Retention Analyzer

จับคู่ Audience Retention กับสคริปต์

วางผลลัพธ์ AI ของตอนนี้ในแท็บหลักแล้วกดวิเคราะห์ก่อน จึงจะ match retention กับสคริปต์ได้

วางข้อมูลจาก YouTube Studio (Advanced mode → Audience retention → Export CSV) หรือพิมพ์เองบรรทัดละจุด เช่น 1:45 62% (คงเหลือ) หรือ 1:45 -8% (หายไป) — ไม่มีการเรียก API ใดๆ ในแท็บนี้
