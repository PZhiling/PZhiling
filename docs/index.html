Packaging Studio

Title A/B/C + Thumbnail + Tags

ปก + ชื่อคลิปคือตัวตัดสิน CTR ก่อนใครได้ยินเสียงคุณ — สร้าง 3 ชื่อคนละมุม, คอนเซปต์ปก 2 แบบ (เจนภาพได้เลย), และ Tags 15 อัน

B-Roll Studio

เจนภาพประกอบจาก Storyboard

ดึง Prompt จากตาราง Storyboard (Phase 2) มาเจนภาพ 16:9 ในแอปด้วย key เดิมของคุณ — เจนทีละภาพเพื่อประหยัดโควตา แล้วกดดาวน์โหลดไปตัดต่อได้เลย

Shorts Studio

ตัดตอนเต็มเป็น Shorts 3 คลิป

Shorts คือท่อส่งคนเข้าตอนเต็ม — สร้างสคริปต์สั้น ~45-60 วิ 3 คลิปจากจุดพีคของตอน พร้อม Hook, CTA และ Hashtags

Retention Analyzer

จับคู่ Audience Retention กับสคริปต์

วางผลลัพธ์ AI ของตอนนี้ในแท็บหลักแล้วกดวิเคราะห์ก่อน จึงจะ match retention กับสคริปต์ได้

วางข้อมูลจาก YouTube Studio (Advanced mode → Audience retention → Export CSV) หรือพิมพ์เองบรรทัดละจุด เช่น 1:45 62% (คงเหลือ) หรือ 1:45 -8% (หายไป) — ไม่มีการเรียก API ใดๆ ในแท็บนี้
