# ตำนานนักสู้ · Legend Fighters

เกมต่อสู้แนว **Little Fighter 2** เล่นบนเบราว์เซอร์ แนวนอน คุมด้วยจอสัมผัส
15 ตัวละคร 10 ด่าน วาดด้วยโค้ดทั้งหมด ไม่ต้องมีไฟล์ภาพหรือเสียงก็เล่นได้ครบ

เปิดที่ `/game/` (`npm run dev` → http://localhost:3000/game/)

---

## เล่นยังไง

| | จอสัมผัส | คีย์บอร์ด |
|---|---|---|
| เดิน / เข้า-ออกความลึก | ลากนิ้วซ้ายของจอ | ลูกศร หรือ WASD |
| วิ่ง | แตะทางเดิมสองครั้ง | กดทางเดิมสองครั้ง |
| ตี (คอมโบ 3 ไม้) | ปุ่ม **ตี** | `J` |
| กระโดด | ปุ่ม **กระโดด** | `K` / Space |
| กัน | ปุ่ม **กัน** | `L` |
| จับทุ่ม | กัน + ตี แล้วกระโดดเพื่อทุ่ม | `L` + `J` |
| สกิล 1–4 (ที่ 4 คือท่าไม้ตาย) | ปุ่มกลม 4 ปุ่ม | `1`–`4` หรือ `U I O P` |
| พัก | ปุ่มขวาบน | `Esc` |

## โครงสร้าง

```
game/
  index.html          หน้าเกม (fullscreen + ล็อกแนวนอน)
  src/
    main.ts           state machine ของทั้งเกม + game loop
    core/
      input.ts        คีย์บอร์ด + จอยเสมือน → Command
      audio.ts        สังเคราะห์เสียงด้วย WebAudio (+ สลับเป็นไฟล์จริงได้)
      assets.ts       ระบบสลับ asset จาก manifest.json
      math.ts rng.ts  helper + PRNG แบบ seed ได้
    sim/              การจำลอง — ไม่รู้จัก canvas เลย
      types.ts        โครงข้อมูลทั้งหมด
      actions.ts      ท่าพื้นฐานที่ทุกตัวละครใช้ร่วมกัน
      world.ts        ฟิสิกส์ การชน ดาเมจ ระลอกศัตรู กล้อง
      ai.ts           AI ศัตรู (คิดตาม archetype)
    data/
      characters.ts   15 ตัวละคร + ท่าประจำตัว
      stages.ts       10 ด่าน + ระลอกศัตรู + บรีฟเพลง
      projectiles.ts  คลังกระสุน/คลื่น/ลำแสง
    gfx/
      pose.ts         คลังท่าโครงกระดูก
      rig.ts          วาดตัวละครจากโครงกระดูก + Look
      fx.ts           particle system
      backdrop.ts     ฉากหลัง procedural 10 ธีม
      renderer.ts     กล้อง projection 2.5D + ลำดับการวาด
    ui/
      hud.ts          หลอดเลือด/พลัง คอมโบ ปุ่มบนจอ
      screens.ts      เมนูทั้งหมด
```

### จุดตัดสินใจสำคัญ

**การจำลองแยกขาดจากการวาด** — `sim/` รับแค่ `Command` (โครงเล็ก ๆ ที่
serialize ได้) แล้วเดินด้วย fixed timestep 60 Hz พร้อม PRNG ที่ seed ได้
ผลคือรันซ้ำแล้วได้ผลเหมือนเดิม ซึ่งเป็นเงื่อนไขที่ทำให้เติม **multiplayer
แบบส่ง input ข้ามเครื่อง** ทีหลังได้โดยไม่ต้องรื้อ (คีย์บอร์ด จอสัมผัส และ AI
ผลิต `Command` หน้าตาเดียวกันอยู่แล้ว)

**ท่าทุกท่าเป็นข้อมูล ไม่ใช่โค้ด** — เฟรมหนึ่งพก ความเร็ว กล่องโจมตี การเสก
และเอฟเฟกต์ไว้ในตัว การปรับบาลานซ์หรือเพิ่มตัวละครจึงเป็นการแก้ตาราง
ไม่ใช่การเขียนตรรกะใหม่

**ตัวละครวาดจากโครงกระดูก ไม่ใช่ sprite sheet** — ท่าเดียวใช้ได้กับทั้ง 15 ตัว
และท่าเชื่อมกันแบบ interpolate ได้ (sprite ทำไม่ได้) พอมีภาพจริงแล้ว
`assets.ts` จะสลับไปใช้ sprite แทนให้เอง ทีละตัวก็ได้

**คุณภาพเอฟเฟกต์ปรับอัตโนมัติ** — เรนเดอร์วัดเวลาต่อเฟรม ถ้าเครื่องช้า
จะลดจำนวน particle และปิด after-image ก่อน แทนที่จะปล่อยให้เฟรมตก

## ใส่ภาพ/เสียงที่เจนมา

ทุกอย่างสลับผ่าน `public/game/assets/manifest.json` ทีละชิ้นได้:

| ช่อง | แทนที่อะไร |
|---|---|
| `portraits` | รูปตัวละครในหน้าเลือกตัว |
| `characters` | sprite sheet ตัวละครในสนาม (แทนตัวที่วาดด้วยโครงกระดูก) |
| `stages` | ฉากพื้นหลัง parallax |
| `effects` | เอฟเฟกต์เป็น sprite animation (แทน particle ที่วาดด้วยโค้ด) |
| `icons` | ไอคอนบนปุ่มสกิลและไอเทม |
| `music` / `sfx` | เพลงและเสียง |

ดู [`docs/GAME-ASSETS.md`](../docs/GAME-ASSETS.md) — มี prompt พร้อมวางสำหรับ
ChatGPT ครบทั้ง 15 ตัวละคร 10 ฉาก 24 เอฟเฟกต์ 60 ไอคอนสกิล
และ prompt เพลงของทั้ง 10 ด่านสำหรับ Google Flow

## ยังไม่ได้ทำ

- **Multiplayer** — โครงรองรับแล้ว (`World.step()` รับ `Map<pad, Command>`)
  แต่ยังไม่มีชั้นเน็ตเวิร์ก ขั้นต่อไปคือ WebSocket room server ที่รีเลย์ input
- โหมด versus / survival
- บันทึกรีเพลย์ (ทำได้แล้วในทางเทคนิค เหลือแค่ UI)
